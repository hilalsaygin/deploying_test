GETINFLUENCED

GETINFLUENCED is a web application that ranks Instagram influencers based on their interaction rates and categorizes profiles using raw profile data. The platform utilizes data classification techniques to provide insights into influencer performance. The project follows agile methodologies, including Scrum meetings and structured task management.

Tech Stack
Backend: NodeJS, REST API, Instagram GraphAPI, META
Frontend: ReactJS
Database: MongoDB
Data Processing: Python, Numpy, Classification
Features
Influencer Ranking: Calculates engagement and interaction rates.
Profile Categorization: Classifies influencers based on profile attributes.
Data Processing: Uses Python and Numpy for classification.
REST API Integration: Fetches data using Instagram GraphAPI.
Agile Development: Project management with Scrum methodologies.
